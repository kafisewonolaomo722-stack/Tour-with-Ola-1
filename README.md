# Tour with Ola

Tourism website for Badagry, Lagos State, Nigeria. Contact: kafisewonolaomo722@gmail.com

Every page is a single self-contained file: the photos, styles and scripts are built in, so there is no image folder to upload.

## Put it online with GitHub Pages (works from a phone)
1. On github.com create a new Public repository named `tour-with-ola`.
2. Tap **uploading an existing file** and choose ALL the files from this folder (index.html, attractions.html, museums.html, tickets.html, about.html, contact.html, 404.html, robots.txt). index.html must be included.
3. Tap **Commit changes**.
4. Go to **Settings > Pages**, choose **Deploy from a branch**, branch **main**, folder **/ (root)**, and Save.
5. After 1-2 minutes the site is at https://YOUR-USERNAME.github.io/tour-with-ola/

Prices are sample figures; edit them in tickets.html.
